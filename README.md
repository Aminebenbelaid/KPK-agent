# KeinplanKarriere — project website

This branch contains **only the published project website**, with the site at the branch root
so GitHub Pages can serve it directly (Settings → Pages → branch `website`, folder `/ (root)`).

- `index.html` — the project website (self-contained: styles, walkthrough script, no build step)
- `assets/` — product screenshots used by the page
- `KeinplanKarriere-Pitch.pdf` — the project pitch deck
- `.nojekyll` — serve files as-is, without Jekyll processing

The application source code lives on the [`main`](https://github.com/Aminebenbelaid/KPK-agent/tree/main) branch.
